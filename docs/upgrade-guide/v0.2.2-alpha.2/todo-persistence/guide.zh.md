# `todo_write` 列表在被显式清空前持续存在

[English](guide.md) | 中文

## 变更

`dsh-tool-todo` 的 `todo_write` 列表以前会在每轮开始时被重置为空，因此一轮中写入的计划到下一轮就消失了，不得不重新输入。现在它会跨轮次、跨重新打开或恢复的会话持续存在，直到模型显式清空。

谁注意到该变更：依赖轮次开始时列表为空的用户与 agent。持久化的列表现在显示最后一次 `todo_write` 记录的内容；清空它是一个显式动作。

## 迁移

1. 如果你依赖轮次开始时列表为空，请显式清空：模型调用 `todo_write` 且 `todos: []`，或人工使用 `/todo clear`。
2. 确认方式：写入一个列表并开始新轮次或恢复会话后，同一列表仍会显示；显式空 `todo_write` 会将其清空。
